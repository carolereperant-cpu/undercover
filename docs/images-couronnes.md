# Les Quatre Couronnes : images à générer (Google Flow)

**Comment faire :** pour chaque carte, copie le style commun puis la description. Enregistre l'image sous le nom indiqué (colonne *Fichier*) et mets-la dans le dossier `client/public/cartes/`. Formats acceptés : .png, .jpg ou .webp. Une carte sans image affiche un dessin de secours (emoji de la faction).

**Style commun (à mettre au début de chaque description) :**

> Illustration de carte de jeu fantasy, peinture numérique, cadrage portrait 3:4, personnage ou objet au centre, éclairage dramatique, fond simple et flou, aucun texte, aucun logo, aucun cadre

**Conseil :** génère d'abord 2 ou 3 cartes de la même faction, garde le rendu qui te plaît, puis réutilise exactement le même style pour les autres afin que tout le jeu se ressemble.
